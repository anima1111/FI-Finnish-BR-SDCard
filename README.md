# Bible Reader content — FI-Finnish

This repository contains the Bible Reader SD-card content for **FI-Finnish**.

## Directory layout

- `text/FI-Finnish/` — all Bible translations and their original nested folder structure.
- `audio/FI-Finnish/` — audio Bible book folders and chapter MP3s.
- `gospel/FI-Finnish/` — Gospel files, retaining original names such as `Gospel.txt` and `Gospel.mp3`.

Copy these folders into the root of the Bible Reader `SDCARD` staging directory.
Do not rename files or flatten directories: the firmware expects the original paths.
